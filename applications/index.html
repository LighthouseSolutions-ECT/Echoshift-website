Rotating machinery applications

Rotating machinery vibration diagnostics

EchoShift provides vibration diagnostics and condition monitoring across motors, pumps, gearboxes, mixers, fans, conveyors, compressors and other rotating machinery, with measurement points chosen around the actual machine and maintenance concern.

Request a diagnosticExplore applications
How application scope works
  • Measure rigid points close to bearings and load paths
  • Use speed, load and machine configuration as diagnostic context
  • Follow the motor, transmission and driven component where useful
  • Identify the next useful check when vibration alone cannot close the question
